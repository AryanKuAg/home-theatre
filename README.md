# Atelier Noir

A local-only cinematic home-theatre website built with Vinext, React, and ScrollyVideo.js.

## Run locally

1. Install Node.js 22 or newer and pnpm.
2. Run `pnpm install`.
3. Run `pnpm dev`.
4. Open the local URL shown in the terminal.

The hero video is streamed from the configured CloudFront URL, so an internet connection is required for the footage to load.
